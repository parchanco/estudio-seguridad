# 🔐 Estudio de Seguridad de Aplicaciones

Repositorio personal de estudio sobre seguridad práctica para desarrolladores:
cómo se rompen las aplicaciones web y cómo se defienden. No es hacking
ofensivo — es la seguridad que un fullstack debe llevar puesta.

## Material base

| Recurso | Papel |
|---|---|
| OWASP Top 10 + OWASP Cheat Sheet Series | El estándar de facto, gratuito |
| *The Web Application Hacker's Handbook* | Profundidad en el lado ofensivo (para defender mejor) |
| OWASP WebGoat / PortSwigger Web Security Academy | Laboratorios prácticos gratuitos |

## Conexiones con los otros repos

Amplía el bloque 9 (seguridad) de `temario-telecomunicaciones`, que es
conceptual (cifrado simétrico/asimétrico, TLS, VPN) — aquí se baja a la
práctica de aplicación. La autenticación y los límites conectan con
`estudio-programacion` (curso 04) y los secretos con `curso-docker` y
`aws-architect`.

## Enfoque ético

Todo el contenido es **defensivo y educativo**: se estudia cómo funcionan los
ataques para poder prevenirlos en tu propio código, practicando solo en
laboratorios diseñados para ello (WebGoat, entornos propios). Nunca contra
sistemas de terceros.
